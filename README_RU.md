# NEBULA Messenger — стартовый Android-проект

Это стартовый проект Android-приложения на Kotlin + Jetpack Compose с интерфейсом мессенджера и демонстрационным кошельком NBC.

## Важно
- Это **прототип интерфейса**, а не готовая публичная служба обмена сообщениями.
- Чаты и баланс в текущей версии демонстрационные и хранятся локально в памяти приложения.
- Для настоящих аккаунтов, доставки сообщений между устройствами и серверной валюты нужно подключить Supabase и настроить политики безопасности.
- APK не собран в этой среде: для сборки требуется Android SDK/Android Studio.

## Как собрать APK
1. Установите Android Studio: https://developer.android.com/studio
2. Откройте папку `nebula_messenger` как проект.
3. Дождитесь синхронизации Gradle.
4. Подключите Android SDK, если Android Studio попросит.
5. Для тестового APK выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
6. APK обычно появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Подключение бесплатного облачного backend
1. Создайте проект на https://supabase.com/
2. Создайте таблицы по примеру в `supabase/schema.sql`.
3. В `app/src/main/java/com/nebula/messenger/data/BackendConfig.kt` укажите Project URL и anon key.
4. Перед публичным запуском настройте RLS, лимиты и правила кошелька. Не помещайте service_role key в Android-приложение.

## Включено в прототип
- Экран чатов в тёмной теме с фиолетовым акцентом.
- Демонстрационный экран диалога.
- Профиль и виртуальный баланс NBC.
- Экран перевода монет (локальная демонстрация).
- Каркас SQL для дальнейшего подключения Supabase.
